## 一句话机制速查

| 机制 | 一句话 |
|---|---|
| 热量 | 球、生物、方块三套热量**双向叠加**，按「当前速度 ÷ 出手速度」折算效率，**停住的球不加热** |
| 【感应】 | 在金属附近积热，热量决定球会不会【熔融】/【引雷】/【融化】 |
| 【磁吸】 | 只把身边的金属**拽过来**，球自己不改向 |
| 【磁性】 | 球**自己拐弯**去追金属目标 |
| 弩 | 副手持球 + 主手拿弩即可发射，`#more_balls:balls` 标签里的一切都能当弹药 |
| 组合球 | 2 半球或 4 四分之一球拼成，名字/贴图/词条按摆放顺序生成 —— **始终是一件物品** |
| 熔融物烧伤 | 对**高甲**目标特攻的持续灼烧，目标**必须有金属装备**才生效 |
| 【魔法】 | 命中给目标随机 debuff、回收给主人随机 buff，**0.1% 抽中大奖**给 60 秒【不灭】 |
| 不灭 | 效果期间**不掉血、不会死**、血量恒 ≥ 1，**回血照常** |

本页所有数值均来自模组源码中的**常量定义**，非估计值。
