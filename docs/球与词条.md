### 几个字段的含义

| 字段 | 含义 |
|---|---|
| **伤害** | 直接命中的基础伤害值 |
| **坚固** | 耐久（能碰撞几次）。`不坚固` = 命中一次即碎 |
| **重量** | 影响弹道下坠与射程 |
| **弹性** | 落地/撞墙后弹跳的强度，0 = 不弹 |
| **蓄力** | 按住右键可蓄力的级数，级数越高初速度越快 |

### 特殊说明

- **金球的渲染尺寸是普通球的 2 倍**（本意为适配“变形”词条做的，所以视觉上更大，后发现没啥必要的时候已经不敢动了，就这样吧）
- **紫水晶球的【智慧5】**：可锁定 5 次（**每次成功锁定**才消耗 1 次机会，空追不扣次数）
- **铜球 / 空心铜球 / 雪球-铜粒 的【感应2】**：那个「2」只是等级标示，**不代表积热更快** —— 热量效率只按「当前速度 / 初速度」折算（停住的球效率为 0，不凭空积热）
- 本mod内所有的雪球类型共享同一个使用冷却（原版雪球照常扔出）

## 二、词条总表

| 词条 | 效果 |
|---|---|
| **【智慧 x】** | 发射后扫描 10 格内无遮挡可直达的敌对 / 仇恨中生物，锁定并转向。**玩家也算合格目标**（怪物拿它扔玩家时照样锁定）。**怪物持有的球会锁定怪物自己的目标**。x 是可追踪次数，**每次成功锁定扣 1**（没锁到不扣） |
| **【善良】** | 不伤害友好与中立生物，碰到它们改为**反弹** |
| **【导电】** | 实体状态下像避雷针一样吸引**闪电**（半径 32 格），每次被劈消耗 1 点耐久 |
| **【引雷 x】** | 热量满 x 时释放 **4–9 道**闪电并**清空热量**。按优先级选目标（避雷针 = 铜球 ＞ 带金属装备的生物 ＞ 其它铜制方块 ＞ 无装备生物 ＞ 其它方块），同一实体一次雷击只中一次。**总伤固定 60，按「放出去的道数」平摊** —— 放 6 道中 2 个，那两个各吃 10 点，落空那 4 道的份额浪费掉；**每道不超过 20**（实际上限是 60 ÷ 4 = 15）。**对玩家减伤 80%**，怪物照常挨满。闪电用的是原版 `LightningBolt` 实体与 `lightning_bolt` 伤害类型，只是不走原版结算（否则 9 道各自 5 点还会叠加，总伤不可控）。**不会触发原版的生物转化**（详见下节） |
| **【电击】** | 该球造成的伤害按**闪电类型**结算（击杀归属仍算投掷者） |
| **【感应 x】** | 在金属附近累计热量；热量改变方块与生物的状态（详见[热量系统](热量系统)）。x 是**等级标示**，不是导热倍率 —— 积热快慢只由「当前速度 / 初速度」决定 |
| **【磁吸】** | 飞行时把路径上的**金属掉落物与生物**拽向自己（球不改向）。生物按身上的金属装备数加权：`速度 = 球速 × 0.5 × (装备数 + 1) / 2`，**没穿金属的也会被拽（弱一半）** |
| **【磁性】** | 飞行时**自己朝铁磁性目标偏航** |
| **【融化 x】** | 自身热量满 x 时**球自己化掉** |
| **【熔融 x】** | 热量满 x 后**命中目标**会挂上「熔融物烧伤」1秒 |
| **【点金】** | 命中方块时把命中面那一片石头类方块点成矿物 |
| **【金光闪闪】** | 金球砸猪灵不吸引仇恨；猪灵捡起金球当场交易，**没被这颗球打过**会触发「特殊交易」 |
| **【变形】** | 耐久耗尽时随机变成自身材质对应的方块 |
| **【脉冲】** | 命中时以命中点为球心、半径 7 格判定：有金属装备或护甲值 > 20 的吃【震荡】3 秒；金属装备 ≥ 4 件或护甲值 ≥ 40 的升级成【震荡 II】5 秒 |
| **【照明】** | 球心向下张开正四棱锥判定区（底面半对角线 = 高度 × tan(30°)）。区内生物每待 1 tick 叠 1 秒发光，**不做视线检测，隐身与穿墙也照得出来** |
| **【穿透 x】** | 自带穿透，能连着打穿 x 个目标 |
| **【破坏王】** | 撞碎运动路径上的下一块方块：每碎一块速度降到 85%、扣 1 点耐久。**总共只有 10 次额度**（用完就不再破坏）；掉到静止阈值以下就收手落定。**只对「钻石级工具挖得动」的方块生效**（镐 / 斧 / 锹挖得动、且不要求下界合金等级）；硬度 < 0 的方块（基岩那类）与黑曜石、远古残骸都砸不动 |
| **【透镜】** | 白天晴天时，给正下方 5×5×2 的方块与生物每 5 刻积 1 点热（**球静止也照常**）。矿物走原有机制；木头泥土这类 50 点冒火、100 点真的烧起来 |
| **【魔法】** | **命中目标**：随机施加 **1–20 秒、I–V 级**的负面效果。**回收成功**：对主人随机施加同范围的正面效果（不含本模组的【不灭】）。**另有 0.1% 概率抽中大奖**，给主人 **60 秒【不灭】** 并播放不死图腾的音效与粒子 |
| **【潮涌】** | 球**进入水里**后（雨天不算）不受重力、**也不受阻力**（速度不衰减），速度变为当前值的 **3 倍**，并在四周环绕玩家用激流三叉戟时那圈纹理特效；进入时播放三叉戟的激流音效。从水底射出后**离开水面即结束**、还原重力；**再落回水面会重新触发**；直到停止 |
| **【忠诚】** | **只对完整的一颗球生效**（切开不继承、不参与合成）。球永远带忠诚效果，静止后自己飞回主人手里；**且不会被任何生物捡起、也不会被接住** |
| **【移形换位】** | 末影珍珠（含带它的组合球）击中**其它生物**时与它**交换位置**，原版的瞬移效果保留 |
| **【敛财】** | 命中时给被击中者挂【腰缠万贯】（10 秒）：期间它每次受击有 15% 概率掉 1 个矿物产物 |
| **【尖刺】** | **击中 / 碰撞 / 破碎**时都会触发：以「垂直于速度的面」为基准面，在该面内取 8 个方位，每个方位**朝上抬起、与基准面成 60°** 射出，飞行**最高点 2 格** —— 一圈朝上张开的伞，共 8 枚**最小的滴水石锥**（基础伤害 3，其余按原版结算；命中即消失、不落地变方块） |
| **【招蜂引蝶 n】** | 击中时召唤 n 只**血量 3**、对被击中者有仇恨的蜜蜂，并强制把被击中者的仇恨转移到它们身上。这些蜜蜂**会一直咬住目标**（走原版中立怪的愤怒机制，仇恨不衰减到目标消失为止），而且**球不会打中它们**（免得蜂群内讧）。**数值类特性**：切开均分、合成相加后取整 |
| **【封印】** | 击中**非盟友且非自身的玩家**：随机让它快捷栏里的一件物品进 3 秒冷却；击中**怪物**：打掉它手里的**球**（原本持有的弓 / 弩 / 剑**不掉**）并封它 **10 秒攻击** —— 期间无法发起任何攻击、也无法捡球 |
| **【滋养】** | **组合类**特性词条（见下文）：完整球里**携带但不生效**；**回收成功**那一刻按概率给主人 **3 秒生命恢复**。概率随份数走：一份碎片 25%、两份 50%、四份合起来 100% |

> ⚠️ **【磁吸】与【磁性】是两个不同词条**，别混：
> **磁吸**把金属掉落物拉向球，**磁性**让球飞向金属。

## 三、【引雷】为什么不转化生物

**这不是 bug，是设计结果。**

【引雷】放出的闪电**不会**触发原版的生物转化：

| 生物 | 原版被雷劈 | 【引雷】劈它 |
|---|---|---|
| 猪 | 变成**僵尸猪灵** | **无变化** |
| 村民 | 变成**女巫** | **无变化** |
| 苦力怕 | 变成**高压苦力怕** | **无变化** |

原因：这些闪电是**只走视觉与伤害结算**的 —— 它们不会走原版那套「闪电落地时对周围做转化」的完整结算，
伤害由模组自己接管（总伤按 60 点分摊、**每道最低 5 点**，而不是 4~9 道各自结算）。

**所以想靠【引雷】批量刷僵尸猪灵 / 女巫 / 高压苦力怕是行不通的。**

## 四、组合球

把 **2 个半球**（上下摆）或 **4 个四分之一球**（2×2 摆）合起来，
就是一颗由那些材质拼成的球 —— 名字、贴图、词条都按**摆放顺序**生成。

**同一组材质只会是一件物品**，不会注册出一堆 id。也就是说：

- 组合球是「一个物品 + 数据组件」的做法
- 部件用什么材质，成的球就带什么词条 —— 可以拼出很离谱的强度
- 用**切石机**可以把球切成半球或四分之一，再拼回去（配方类型是自定义的 `more_balls:ball_cutting`，继承原版 `StonecutterRecipe`，所以只在切石机里用，没有剪刀配方）

## 六、切割门槛与铁砧修复

### 切割门槛

**有耐久的球：耐久 ≥ 80% 才能切**（作者 2026-10-13 指定）。

表现上就是：耐久条掉到 80% 以下时，这颗球**放不进切石机**。
口径与耐久条百分比完全一致（上限取球的坚固值、剩余取实际剩余次数）。

**不坚固的球（坚固 0，碰上就碎的那一档）视为满耐久，随时能切**（作者 2026-10-15 明确）——
末影珍珠、蜜饯球、符箓球都属于这一档；它们压根没有耐久条可掉，80% 那条对它们没有意义。
（不这样处理的话，蜜饯球的【滋养】是**组合类**词条，切不动就等于那条机制拿不到。）

### 铁砧修复

**所有球都支持铁砧修复**：左边放受损的球、右边放一颗**同种球**即可。

| 球的种类 | 「同种」怎么判 |
|---|---|
| 普通球 | 物品相同 |
| **组合球** | 四个组件**分别一致即可，顺序可以不一样**（即四组件的多重集相等） |

修复量照原版铁砧的手感：两颗的剩余耐久相加，再额外给上限的 **12%**，封顶到上限；
等级消耗按「补了多少比例」折算（补满约 30 级），材料消耗 1。

## 六、切球与重组的词条规则

把一颗球切开再合回去，词条**不是简单地除以份数再乘回来**。
按词条的性质分成**六类**，各走各的规则：

| 类别 | 词条 | 切开 | 合成 |
|---|---|---|---|
| **数值类基础** | 【基础伤害】【重量】【初速度】【弹性】【蓄力n】【坚固(n)】【感应n】 | **均分** | **相加，向下取整** |
| **阈值类基础** | 【融化n】 | **不变** | **取同种最低** |
| **数值类特性** | 【智慧n】【穿透n】【破坏王n】【招蜂引蝶n】 | **均分** | **相加，向下取整** |
| **阈值类特殊** | 【引雷n】【熔融n】 | **不变** | **取最高** |
| **其它特殊** | 【变形】【磁性】【善良】【导电】【电击】【脉冲】【照明】【透镜】【魔法】【移形换位】【潮涌】【敛财】【尖刺】【封印】 | 原样保留 | **≥1 份即携带** |
| **组合类** | 【滋养】 | **按概率均分**（每份 1/份数） | **相加**，≥1 份即生效 |
| **唯一特殊** | 【金光闪闪】【忠诚】 | **不继承** | **不参与合成** |

> ⚠️ **【初速度】并不在 `Fragment` 的字段里** —— 它由 `withWeight` 按**重量重算**（基准 10 对应雪球重量 4，每重 1 点减 1）。
> 也就是说改重量就等于改初速度，两者不能分开设；切开 / 合成时也不用单独处理它，它会跟着重量自己走。
> （【基础伤害】【重量】【弹性】【蓄力】是组合时按「各份 × 1/份数 相加 → 向下取整」单独算的。）

**份数判定**（2026-10-13 起）：二合一与四合一**都是「≥1 份即携带」** ——
以前四合一要求 ≥2 份、二合一要求任一份，这套「激活门槛」已经取消了。
（`QUAD_TRAIT_THRESHOLD` 因此不再有使用点，只留作历史。）

**例外**：**「唯一特殊」那一档（【金光闪闪】【忠诚】）永远不继承、也不参与合成** ——
即使四份都带着它，组合球上也拿不到。

### 组合类特性词条（与「唯一特殊」正好相反）

**完整球上携带它、但它不生效**；只有把它切成碎片、再合进组合球，它才会真的起作用。

| | 唯一特殊（【金光闪闪】【忠诚】） | **组合类（【滋养】）** |
|---|---|---|
| 完整球 | 生效 | **不生效**（shift 折叠信息里显示成「**（当前未生效）【滋养】**」） |
| 切开 | 不继承、永久失效 | **按份数均分触发概率**（四分之一球各 25%） |
| 组合球 | 不参与合成 | **生效**，且显示在组合球的默认信息里 |

例：一颗蜜饯球是【滋养】100%。切成四个四分之一球，每个带着 **25%**；
用其中两个合成组合球 → **50% 概率**在回收成功时触发；四个都用上 → 100%。

### 几个例子

**【基础伤害】10** 切成四个四分之一球，每个是 **2.5**。
取其中两个，再配两个来自【基础伤害】1 的球的四分之一球：

```
2.5 + 2.5 + 0.25 + 0.25 = 5.5  →  取整  →  【基础伤害】5
```

**【智慧】5** 切成四个四分之一球，每个是 **【智慧 1.25·未激活】**（单份不显示、也不生效）。
配两个没有【智慧】的四分之一球：

```
只有 1 份智慧 → 不够份数 → 不显示、不生效
2 份智慧     → 1.25 + 1.25 = 2.5  →  取整  →  【智慧】2
```

**【引雷】120** 切开后**四份都还是 120**（阈值不缩放），再与一个【引雷】90 的球合成 → **取最高 → 120**。

**【融化】200** 切开后四份都是 200，合成时**取最低** —— 阈值越低越容易融化。

### 存储上限

收纳袋的弹药段与转运段各有 **54 格**的存储上限（实际可用格数由袋子等级决定，见
[弩 · 附魔 · 收纳袋](弩-附魔-收纳袋)）。旧存档里的段读取时会自动补齐，**不会丢东西**。
