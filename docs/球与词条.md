### 几个字段的含义

| 字段 | 含义 |
|---|---|
| **伤害** | 直接命中的基础伤害值 |
| **坚固** | 耐久（能碰撞几次）。`不坚固` = 命中一次即碎 |
| **重量** | 影响弹道下坠与射程 |
| **弹性** | 落地/撞墙后弹跳的强度，0 = 不弹 |
| **蓄力** | 按住右键可蓄力的级数，级数越高初速度越快 |

### 特殊说明

- **金球的渲染尺寸是普通球的 2 倍**（本意为适配“变形”词条做的，所以视觉上更大，后发现没啥必要的时候已经不敢动了，就这样吧）
- **紫水晶球的【智慧5】**：可锁定 5 次（每次命中消耗 1 次机会）
- **铜球 / 空心铜球 / 雪球-铜粒 的【感应2】**：积热速度是非铜球的两倍（导热性好）
- 本mod内所有的雪球类型共享同一个使用冷却（原版雪球照常扔出）

## 二、词条总表

| 词条 | 效果 |
|---|---|
| **【智慧 x】** | 发射后扫描 10 格内无遮挡可直达的敌对 / 仇恨中生物，锁定并转向。**怪物持有的球会锁定怪物自己的目标**。x 是可追踪次数 |
| **【善良】** | 不伤害友好与中立生物，碰到它们改为**反弹** |
| **【导电】** | 实体状态下像避雷针一样吸引**闪电**（半径 32 格），每次被劈消耗 1 点耐久 |
| **【引雷 x】** | 热量满 x 时释放 **4–9 道**闪电并**清空热量**。按优先级选目标，总伤 60 分摊，同一实体一次雷击只中一次。**不会触发原版的生物转化**（详见下节） |
| **【电击】** | 该球造成的伤害按**闪电类型**结算（击杀归属仍算投掷者） |
| **【感应 x】** | 在金属附近累计热量；热量改变方块与生物的状态（详见[热量系统](热量系统)）。x 是导热倍率 |
| **【磁吸】** | 飞行时把路径上的**金属掉落物与生物**拽向自己（球不改向）。生物按身上的金属装备数加权：`速度 = 球速 × 0.5 × (装备数 + 1) / 2`，**没穿金属的也会被拽（弱一半）** |
| **【磁性】** | 飞行时**自己朝铁磁性目标偏航** |
| **【融化 x】** | 自身热量满 x 时**球自己化掉** |
| **【熔融 x】** | 热量满 x 后**命中目标**会挂上「熔融物烧伤」1秒 |
| **【点金】** | 命中方块时把命中面那一片石头类方块点成矿物 |
| **【金光闪闪】** | 金球砸猪灵不吸引仇恨；猪灵捡起金球当场交易，**没被这颗球打过**会触发「特殊交易」 |
| **【变形】** | 耐久耗尽时随机变成自身材质对应的方块 |
| **【脉冲】** | 命中时以命中点为球心、半径 7 格判定：有金属装备或护甲值 > 20 的吃【震荡】3 秒；金属装备 ≥ 4 件或护甲值 ≥ 40 的升级成【震荡 II】5 秒 |
| **【照明】** | 球心向下张开正四棱锥判定区（底面半对角线 = 高度 × tan(30°)）。区内生物每待 1 tick 叠 1 秒发光，**不做视线检测，隐身与穿墙也照得出来** |
| **【穿透 x】** | 自带穿透，能连着打穿 x 个目标 |
| **【破坏王】** | 撞碎接触到的方块：每碎一块速度降到 85%、扣 1 点耐久；掉到静止阈值以下就收手落定。硬度 < 0 的方块（基岩那类）砸不动 |
| **【透镜】** | 白天晴天时，给正下方 5×5×2 的方块与生物每 5 刻积 1 点热（**球静止也照常**）。矿物走原有机制；木头泥土这类 50 点冒火、100 点真的烧起来 |
| **【魔法】** | **命中目标**：随机施加 **1–20 秒、I–V 级**的负面效果。**回收成功**：对主人随机施加同范围的正面效果（不含本模组的【不灭】）。**另有 0.1% 概率抽中大奖**，给主人 **60 秒【不灭】** 并播放不死图腾的音效与粒子 |

> ⚠️ **【磁吸】与【磁性】是两个不同词条**，别混：
> **磁吸**把金属掉落物拉向球，**磁性**让球飞向金属。

## 三、【引雷】为什么不转化生物

**这不是 bug，是设计结果。**

【引雷】放出的闪电**不会**触发原版的生物转化：

| 生物 | 原版被雷劈 | 【引雷】劈它 |
|---|---|---|
| 猪 | 变成**僵尸猪灵** | **无变化** |
| 村民 | 变成**女巫** | **无变化** |
| 苦力怕 | 变成**高压苦力怕** | **无变化** |

原因：这些闪电是**只走视觉与伤害结算**的 —— 它们不会走原版那套「闪电落地时对周围做转化」的完整结算，
伤害由模组自己接管（这样才能把总伤控制在 60 点，而不是 4~9 道各自结算、把伤害顶到几十上百）。

**所以想靠【引雷】批量刷僵尸猪灵 / 女巫 / 高压苦力怕是行不通的。**

## 四、组合球

把 **2 个半球**（上下摆）或 **4 个四分之一球**（2×2 摆）合起来，
就是一颗由那些材质拼成的球 —— 名字、贴图、词条都按**摆放顺序**生成。

**同一组材质只会是一件物品**，不会注册出一堆 id。也就是说：

- 组合球是「一个物品 + 数据组件」的做法
- 部件用什么材质，成的球就带什么词条 —— 可以拼出很离谱的强度
- 用剪刀/切石类配方可以把球切成半球或四分之一，再拼回去

## 六、切球与重组的词条规则

把一颗球切开再合回去，词条**不是简单地除以份数再乘回来**。
按词条的性质分成**六类**，各走各的规则：

| 类别 | 词条 | 切开 | 合成 |
|---|---|---|---|
| **数值类基础** | 【基础伤害】【重量】【初速度】【弹性】【蓄力n】【坚固(n)】【感应n】 | **均分** | **相加，向下取整** |
| **阈值类基础** | 【融化n】 | **不变** | **取同种最低** |
| **数值类特性** | 【智慧n】【穿透n】【破坏王n】 | **均分** | **需要激活**；激活后**相加，向下取整** |
| **阈值类特殊** | 【引雷n】【熔融n】 | **不变** | **需要激活**；激活后**取最高** |
| **其它特殊** | 【变形】【磁性】【善良】【导电】【电击】【脉冲】【照明】【透镜】【魔法】 | 原样保留 | **需要激活** |
| **唯一特殊** | 【金光闪闪】 | **不继承** | **不参与合成** |

**「激活」的判定**：二合一 → 任一份有就算；四合一 → **要 ≥2 份**。

### 几个例子

**【基础伤害】10** 切成四个四分之一球，每个是 **2.5**。
取其中两个，再配两个来自【基础伤害】1 的球的四分之一球：

```
2.5 + 2.5 + 0.25 + 0.25 = 5.5  →  取整  →  【基础伤害】5
```

**【智慧】5** 切成四个四分之一球，每个是 **【智慧 1.25·未激活】**（单份不显示、也不生效）。
配两个没有【智慧】的四分之一球：

```
只有 1 份智慧 → 不够份数 → 不显示、不生效
2 份智慧     → 1.25 + 1.25 = 2.5  →  取整  →  【智慧】2
```

**【引雷】120** 切开后**四份都还是 120**（阈值不缩放），再与一个【引雷】90 的球合成 → **取最高 → 120**。

**【融化】200** 切开后四份都是 200，合成时**取最低** —— 阈值越低越容易融化。
