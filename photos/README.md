## 命名约定

`<两位序号>-<英文短名>.png` —— 有序号方便按顺序在 README 里排。

## 规格建议

- **PNG**，尽量不要超过 1 MB（GitHub 会压，但太大影响克隆速度）
- **游戏截图**：F2 存的原始截图直接可用；想裁掉 HUD 就用任意图片工具裁
- **别放带个人信息的东西**（聊天框里的玩家名、F3 调试里的路径等）

## 引用方式

在 README 里这样写：
