## 简介

这是游戏《Minecraft》基于NeoForge的一个原创mod，在原版Minecraft中，只有雪球和末影珍珠等几种可以投掷的球，这显然是无趣的，所以，我们添加了铜球、氧化的铜球、锈蚀的……好吧开玩笑的。我们添加了各种材质的球，并且不同的球还拥有不同的特性，你可以直接扔出各种各样的球，当然，这些球也可以被弩发射。你甚至把球切开——再合成，组成更多的球，说不定会有变态的强度，我们现在有非常多多的球可以玩了！目前模组支持版本为26.2，NeoForge 26.2.0.88及以上。

**组合球**是「一个物品 + 数据组件」的做法：把 2 个半球（上下摆）或 4 个四分之一球（2×2 摆）
合起来，就是一颗由那些材质拼成的球 —— 名字、贴图、词条都按摆放顺序生成。
**同一组材质只会是一件物品**，不会注册出一堆 id。

### 词条

|词条|效果|
|-|-|
|**【智慧】**|发射后扫描 10 格内无遮挡可直达的敌对/仇恨中生物，锁定并转向。怪物持有的球会锁定怪物自己的目标|
|**【善良】**|不伤害友好与中立生物，碰到它们改为反弹|
|**【导电】**|实体状态下像避雷针一样吸引自然闪电（半径 32 格），每次被劈消耗 1 点耐久|
|**【引雷x】**|热量满 x 时释放 4–9 道闪电并清空热量；按优先级选目标，总伤 60 分摊，同一实体一次雷击只中一次|
|**【电击】**|该球造成的伤害按**闪电类型**结算（击杀归属仍算投掷者）|
|**【感应】**|在金属矿物附近累计热量；热量改变方块与生物的状态（见下）|
|**【磁性】**|飞行时被最近的金属矿物吸引、偏转航向|
|**【融化x】**|自身热量满 x 时球自己化掉|
|**【熔融x】**|热量满 x 后命中目标会挂上「熔融物烧伤」|
|**【点金】**|命中方块时把命中面那一片石头类方块点成矿物|
|**【金光闪闪】**|金球砸猪灵不吸引仇恨；猪灵捡起金球当场交易，没被这颗球打过会触发「特殊交易」|
|**【变形】**|耐久耗尽时随机变成自身材质对应的方块|

### 热量系统

球在三套热量之间流动，**叠加是双向的**（球加热生物的同时自己也被加热），
且按「**当前速度 / 0 级蓄力出手速度**」折算效率 —— **停住的球不加热**。热量过 50 开始冒火焰粒子，泡水散热 ×10。

|层|阈值|表现|
|-|-|-|
|**球自身**|融化 x / 引雷 x / 熔融 x|自化、放电、烫别人|
|**方块（矿物）**|200（粗矿块 1600）|攒够就**烤熟破坏**，掉对应金属锭/块，有额外掉落|
|**方块（其它金属块）**|200 封顶|冒火、**踩上去像岩浆块一样掉血**（不会被破坏）|
|**生物**|着火 100 / 上限 200|着火；满热且穿金属甲 → **持续熔融物烧伤**|

### 收纳袋

七级收纳袋（普通 / 铁 / 金 / 钻石 / 绿宝石 / 黑曜石 / 下界合金），分**弹药段**与**转运段**。
满耐久的球进弹药段、用过的进转运段；主手或副手拿着袋子时捡球直接进袋，地上的球靠近也优先入袋。
装在饰品栏（需 Curios）同样生效。

### 弩与附魔

* **副手持球 + 主手拿弩**即可发射，标签里的一切物品都能当弹药
* **强弩**（3 级）：每级 +30% 基础发射距离
* **轻盈**：弹药重量减半（向上取整，最低 1）
* **空气动力球**：未破碎的球静止后自动飞回作者；回收时对作者造成 1 点物理伤害
* **极速**（5 级）：直接抬高弹药的**初速度**，与强弩**相乘**。逐级累积 ——
  1 级 +10% / 2 级 +20% / 3 级 +35% / 4 级 +50% / 5 级 +70%（倍率 1.10 ~ 1.70）。
  与强弩的区别：强弩走射程换算，极速直接叠在初速度上，两条路不冲突、可以叠加

### 熔融物烧伤

一种挂在**目标身上**的持续灼烧效果（`molten_burn`），**每秒结算一次**伤害，等级越高越痛：

|等级|I|II|III|IV|V|
|-|-|-|-|-|-|
|每秒伤害|2|4|7|10|15|

**等级怎么定** —— 由目标的**护甲值 ÷ 15** 决定（向下取整，封顶 V 级）。**穿得越好，烧得越狠。**

**两种触发方式**：

* 带【熔融】词条的球（如空心铁球的【熔融1000】）热量攒够后**命中目标**即挂上
* 生物自身**热量满 200** 且**穿着金属盔甲**时持续中招

它使用**自己的伤害类型**（`more_balls:molten_burn`，不进货标签），所以死亡提示是「**X 融化了**」。

### 成就（14 个）

从「玩个球啊」开始，涵盖合成、投掷、附魔、组合、被自己的球砸死等等。

## 安装

1. 装 **NeoForge 26.2.0.88** 或更高（26.2 线）
2. 把 `More_Balls-<版本>.jar` 丢进 `.minecraft/mods/`
3. 需要 **Java 25**

**可选联动**（缺失时优雅降级，不会崩）：**JEI**（展示配方）、**AppleSkin**（食物提示）、**Curios**（收纳袋挂饰品栏）。

## 兼容性

* 不硬编码任何他人 mod 的物品 id，一律走标签
* 不覆盖原版注册表内容，只加自己的标签、配方、成就
* 组合球用 `#more_balls:fragments` 系列标签匹配部件，别的 mod 往标签里加东西即可联动
* 水晶配方走 `#more_balls:amethyst_gems` / `#more_balls:amethyst_blocks`，其它来源的水晶加进标签就能用

## 构建

需要 **JDK 25** 与 **Gradle 9.8+**（26.x 线的硬性要求）。`./gradlew build`，产物在 `build/libs/`。

## 版本号规范

四段式 `x.x.x.x`，**数值无上限、不进位**：第 1 段维度、第 2 段功能、第 3 段物品增减、第 4 段修改与修复。
