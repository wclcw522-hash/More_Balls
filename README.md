## 简介

这是游戏《Minecraft》基于NeoForge的一个原创mod，在原版Minecraft中，只有雪球和末影珍珠等几种可以投掷的球，这显然是无趣的，所以，我们添加了铜球、氧化的铜球、锈蚀的……好吧开玩笑的（但是铜球确实有）。我们添加了各种材质的球，并且不同的球还拥有不同的特性，你可以直接扔出各种各样的球，当然，这些球也可以被弩发射。你甚至把球切开——再合成，组成更多的球，说不定会有变态的强度，我们现在有非常多的球可以玩了！目前模组支持版本为26.2，NeoForge 26.2.0.88及以上。

## 安装

1. 装 **NeoForge 26.2.0.88** 或更高（26.2 线）
2. 把 `More_Balls-<版本>.jar` 丢进 `.minecraft/mods/`
3. 需要 **Java 25**

**可选联动**（缺失时优雅降级，不会崩）：**JEI**（展示配方）、**AppleSkin**（食物提示）、**Curios**（收纳袋挂饰品栏）。

## 兼容性

* 不硬编码任何他人 mod 的物品 id，一律走标签
* 不覆盖原版注册表内容，只加自己的标签、配方、成就
* 组合球用 `#more_balls:fragments` 系列标签匹配部件，别的 mod 往标签里加东西即可联动
* 水晶配方走 `#more_balls:amethyst_gems` / `#more_balls:amethyst_blocks`，其它来源的水晶加进标签就能用

## 构建

需要 **JDK 25** 与 **Gradle 9.8+**（26.x 线的硬性要求）。`./gradlew build`，产物在 `build/libs/`。

## 版本号规范

四段式 `x.x.x.x`，**数值无上限、不进位**：第 1 段维度、第 2 段功能、第 3 段物品增减、第 4 段修改与修复。
